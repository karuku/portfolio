# Security policy

This is a portfolio and reference-code repository. Please do not disclose credentials, personal data, or exploitable details in public issues.

If you find a security problem in the sample code, open a private report through GitHub's security advisory workflow when available. Otherwise, contact the repository owner directly through [GitHub](https://github.com/karuku).

Reference modules intentionally keep secrets out of source control. Copy `.env.example` files to local environment files and use a secret manager in deployed environments.
